# HTML5 & CSS Web Link Navigation Demonstration

> Foundational academic web engineering exercise demonstrating HTML5 anchor elements, relative and absolute URL navigation, and responsive CSS styling.

---

## 1. Project Title
**HTML5 & CSS Link Navigation Project** (`DravidProject`) — Web Design Laboratory Demonstration.

## 2. Project Overview
An introductory web development laboratory exercise illustrating standard HTML5 hyperlink conventions, cross-page navigation, target attributes, and hover-state styling with external CSS stylesheets.

## 3. Technology Stack
- **HTML5:** Semantic document markup, anchor tags (`<a>`), navigation blocks.
- **CSS3:** Box model, link pseudoclasses (`:hover`, `:active`, `:visited`), responsive layouts.
